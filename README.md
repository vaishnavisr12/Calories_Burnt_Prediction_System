# Overview
It is a smart calculator that uses machine learning to guess exactly how many calories you burned during a workout. Instead of using a basic formula, it looks at your personal details (Age, Weight) and your workout details (how long you exercised and how fast your heart was beating) to give you an accurate, personalized number.
# Objectives
Give accurate numbers: Use a powerful machine learning model (XGBoost) to predict calorie burn based on real effort, not just generic guessing.

Keep it easy for the user: Make it so the user only has to enter simple stats (like duration and heart rate), while the code automatically handles the complex, hidden details (like body temperature) in the background.

Get instant results: Provide a quick, reusable Python function where you can plug in your numbers and instantly see your results.
