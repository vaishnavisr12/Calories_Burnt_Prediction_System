# Overview
It is a smart calculator that uses machine learning to guess exactly how many calories you burned during a workout. Instead of using a basic formula, it looks at your personal details (Age, Weight) and your workout details (how long you exercised and how fast your heart was beating) to give you an accurate, personalized number.
